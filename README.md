# 💱 Currency converter

Python currency converter with real-time quotation, made as a study project. 
## Features

- Conversion among more than 150 coins
- Quotation update in real time via API
- Error handling (invalid currency, invalid value)
- Allows multiple conversions without restarting the program
- Coloured interface in the terminal

## How to use

1. Clone the repository:
```bash
git clone https://github.com/ddudamorgatto/conversor-de-moedas.git
```

2. Installs the dependencies:
```bash
pip install requests colorama
```

3. Run the program:
```bash
python conversor.py
```

## Technologies

- Python

- [colorama](https://pypi.org/project/colorama/) — Colours in the terminal
- [Currency API](https://github.com/fawazahmed0/exchange-api) — Quotation in real time
